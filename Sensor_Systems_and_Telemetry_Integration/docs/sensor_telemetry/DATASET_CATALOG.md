## Registry convention

Canonical IDs use the investigation prefix, for example `FLEX::pressure_kpa`, `SPICE::smoke_point_length_mm`, and `SAFFIRE::ug_spread_rate_mm_s`. Registry entries preserve source column and source dataset. `measurement_class` distinguishes reported experimental variables from derived results.

## Fields intentionally not treated as sensor readings

Identifiers, test/run labels, dates, material names, quality flags, source references, and other contextual fields are retained as metadata where available. Numeric columns absent from the approved registry are not silently promoted to measurement channels.

## Unit caution

Some source columns have units that are source-defined or not fully specified in the table. Those values remain explicitly described as such in the registry. Do not infer a unit from a variable name or perform conversions until the official data dictionary confirms it.

## Ground-reference separation

The unified 850-row master is described in the supplied research package as 798 microgravity runs plus 52 ground-reference records. The source `gravity_level`/gravity metadata must be retained and filtered appropriately by downstream analytics.
