## How Sensor Systems & Telemetry Integration uses these

- PSI and the supplied research-platform archive are the primary sources for the investigation datasets and variable mapping.
- The combustion-science pages provide scientific context for interpreting oxygen, pressure, flow, flame-spread, extinction and smoke variables.
- Apollo 1, Apollo 13 and Mir are safety-history references. They inform the problem context but are not automatically ingested as sensor datasets.
- Spinoff pages are technology/context references, not evidence that a particular sensor channel exists in the supplied experiment files.
- The video is retained as a project reference; no transcript-derived fields are used in the registry.
